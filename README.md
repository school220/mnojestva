# Кабинет учителя: «Часть множества» (Дроби и группы)

Интерактивная доска, генератор вариантов и конструктор раздаточных карточек для учителя начальной и средней школы по теме **«Часть множества: нахождение дроби от числа с помощью групп кружочков»** (на основе заданий из школьного учебника).

## 👩‍🏫 Специально для учителя

Сайт разработан именно как рабочий инструмент учителя, чтобы **давать задания ученикам, объяснять тему у доски и мгновенно сверяться с ответами**:

## 📚 Полный рабочий лист (4 раздела программы)

В сайт включены **все 4 ключевых типа заданий темы «Часть множества»**, построенные по учебной программе, но со **свежими числами, которых нет в книге**:

---

### 🟠 Задание 1. «Для нахождения ответа выделите группы кружочков»
Интерактивные столбики с капсульным выделением долей:
* **Образец:** $\frac{3}{4}$ части от числа $16 = \mathbf{12}$ *(4 столбика по 4 кружка, 3 выделены)*
* **a)** $\frac{2}{5}$ части от числа $15 =$ `?` *(Ответ: **6**, 5 столбиков по 3)*
* **b)** $\frac{5}{8}$ частей от числа $32 =$ `?` *(Ответ: **20**, 8 столбиков по 4)*
* **c)** $\frac{4}{7}$ части от числа $28 =$ `?` *(Ответ: **16**, 7 столбиков по 4)*

---

### 🔵 Задание 2. «Найдите значения выражений»
Голубая таблица 2х2 с устными и письменными вычислениями:
* **a)** $\frac{1}{3}$ часть от числа $18 = \mathbf{6}$
* **b)** $\frac{4}{5}$ части от числа $25 = \mathbf{20}$
* **c)** $\frac{3}{8}$ части от числа $480 = \mathbf{180}$
* **d)** $\frac{5}{9}$ частей от числа $378 = \mathbf{210}$

---

### 🟠 Задание 3. Текстовая задача: нахождение остатка множества
*Аналог задачи про пуговицы Сожиды:*
> *«У Малики 48 наклеек. Из них $\frac{1}{6}$ часть — с животными, а остальные — с цветами. Сколько наклеек с цветами у Малики?»*
* **Наглядная полоска долей множества (Tape Diagram):** делит отрезок на 6 равных частей.
* **Решение:**  
  1) $48 \div 6 = 8$ (наклеек с животными)  
  2) $48 - 8 = \mathbf{40}$ (наклеек с цветами)  
* **Ответ:** 40 наклеек.

---

### 🟠 Задание 4. Текстовая задача: нахождение целого числа по его дроби
*Аналог задачи про самсу Санобар:*
> *«Бабушка испекла пирожки. $\frac{3}{8}$ части всех пирожков — с вишней, а остальные — с яблоками. Сколько всего пирожков испекла бабушка, если с вишней было 24 пирожка?»*
* **Наглядная полоска долей множества:** показывает, что 3 доли составляют 24 шт.
* **Решение:**  
  1) Находим размер одной доли ($\frac{1}{8}$): $24 \div 3 = 8$ (пирожков).  
  2) Находим всё множество (8 долей): $8 \times 8 = \mathbf{64}$ (пирожка).  
* **Ответ:** всего 64 пирожка.

## 🎲 Готовые наборы заданий (в 1 клик)
* **Набор №1:** базовый комплект (открывается сразу).
* **Набор №2:** комплект с другими персонажами и числами (Тимур со значками, Гульноза с самсой...).
* **Набор №3:** комплект с карандашами и глиняными кувшинами мастера.
* **🎲 Кнопка «Новый вариант»:** случайная генерация всех 4 разделов.

### 3. 👁️ Управление ответами по каждому заданию отдельно
- Под каждым заданием есть персональные кнопки:
  - **«👁️ Ответ: [число]»** — показать ответ только к этому конкретному заданию (удобно при последовательном разборе на уроке).
  - **«📝 Разбор решения»** — отобразить формулу ($12 \div 6 \times 5 = 10$) с разъяснением шагов.
  - **«✏️ Изменить»** — мгновенно поменять числа прямо в задании прямо во время урока!
  - **«🗑️»** — удалить ненужное задание.

### 4. 🖨️ Готовые варианты для печати в один клик
- **«Распечатать для учеников (без ответов)»**:
  - Автоматически скрывает ответы и подсказки.
  - Форматирует страницу как аккуратный печатный рабочий лист с полями:
    `Ученик (ФИО): _______________ Класс: _____ Дата: _____`
- **«Распечатать с ответами (ключи)»**:
  - Печатает готовый лист с выделенными группами, ответами и решениями для быстрой проверки тетрадей учителем.

### 5. 🎲 Генератор вариантов («Вариант 1, Вариант 2...»)
- Кнопка **«Новый вариант»** мгновенно генерирует новый сбалансированный комплект из 3–4 задач с красивыми числами, которые делятся без остатка.

### 6. ➕ Конструктор заданий
- Позволяет учителю добавить любую собственную дробь и число (с предпросмотром и выбором цвета кружков).

## 🚀 Как запустить

### Быстрый запуск
Просто откройте файл `index.html` двойным кликом в браузере (Chrome, Edge, Яндекс, Firefox).

### Через локальный сервер (если требуется)
В папке проекта в терминале:
```powershell
python -m http.server 3000
```
И перейдите по адресу: [http://localhost:3000](http://localhost:3000)
